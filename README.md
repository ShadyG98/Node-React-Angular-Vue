## 💻 Web Development Projects & Skills

This repository showcases theoretical knowledge and exercises across modern web development technologies.

### 🅰️ Angular

* Angular is a TypeScript-based front-end framework for building dynamic single-page applications.
* Component-based architecture
* Dependency injection
* Reactive forms and modularization
* Building responsive user interfaces and managing complex application states

### 🟢 Node.js & MSSQL (CRUD Projects)

* Node.js is a server-side runtime for scalable network applications.
* Designing RESTful APIs
* Performing CRUD operations
* Handling asynchronous operations
* Ensuring data consistency and security with Microsoft SQL Server (MSSQL)

### 🟢 Node.js Exercises

* Practical exercises in Node.js strengthen:
* Server-side programming
* Asynchronous patterns and callbacks
* File system management
* Module system and package management

### ⚛️ React Exercises

* React is a JavaScript library for building interactive user interfaces.
* Component-based architecture
* State and props management
* Lifecycle methods and hooks
* Reusable component design

### 🔵 SignalR with Vue

* SignalR enables real-time web functionality. Combined with Vue.js, it allows:
* Real-time server-to-client communication
* Reactive front-end applications
* Features like live notifications and chat systems
